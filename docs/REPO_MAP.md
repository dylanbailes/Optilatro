## First-party vs vendor

| Tree | Treat as |
|---|---|
| `docs/`, `bench/`, `tools/`, `.github/` | First-party. Safe to reshape. |
| `vendor/balatro-rl/balatro_sim/` + `tests/` | First-party **in practice**. Heavily forked. Edit in place. |
| `vendor/balatro-rl/results/` | Experiment archive. Do not “clean up” JSON without asking. |
| `vendor/balatro-rl/{legacy,mod,launch,balatro_rl,viz}` | Upstream leftover. Read, do not extend. |
| `vendor/balatro-rs/` | Upstream snapshot. Read for RNG/scoring; do not implement features here. |
| `.agents/`, `.freebuff/` | Tooling leftovers (Codebuff / Freebuff). Not part of the agent. |
